Welcome to SimpleWebServer!

If you see this screen, You're properly running the server.

(If you came by double-clicking the "index" inside root, well you're not. Access with http://(your ip):(port in config), or RTFM)


You can place anything inside the root folder defined in the config.json. Default path is (server path)/root.

It is not required to define the routing inside your server.js. Try placing any file to the root folder, then access with http://(server)/(filename).

It will automatically route you to the file. By default, If the file is the html file, You can access it without extension.

try visiting /index, It will automatically send you the same page, but without extension.

(Remember: If you have file like "file1" and "file1.html" at the same time in place, It will automatically choose the "file1" instead of the html.)
